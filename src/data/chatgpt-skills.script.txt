<break time="500ms"/>ChatGPT Skills let you create and reuse your own workflows.

<break time="500ms"/>A Skill teaches ChatGPT a specific way of working. It packages instructions, examples, and optional code into a workflow that ChatGPT can apply whenever it's relevant.

<break time="500ms"/>A Skill is more than a saved prompt. It captures a reusable process, so ChatGPT handles repeated tasks consistently, with less setup each time.

<break time="500ms"/>Skills are especially useful for work that follows a pattern, like weekly updates, meeting summaries, decision memos, and status reports. Instead of explaining the same requirements every time, you give ChatGPT a workflow to reuse.

<break time="500ms"/>At the center of every Skill is a file called SKILL dot M-D. It defines the Skill's name, when it should be used, and the instructions ChatGPT should follow.

<break time="500ms"/>A Skill can also include examples that show the expected style or output, reference files and templates, and optional code that helps ChatGPT run the workflow reliably.

<break time="500ms"/>Once a Skill is installed, ChatGPT can use it whenever it's relevant to the task.

<break time="500ms"/>There are two ways to trigger a Skill.

<break time="500ms"/>You can call it manually. Type the at symbol, and select the Skill from the menu.

<break time="500ms"/>Or ChatGPT can trigger it automatically. When your prompt matches an installed Skill, ChatGPT applies its instructions without you naming it.

<break time="500ms"/>There are three practical ways to create a Skill.

<break time="500ms"/>First, create it in conversation. Ask ChatGPT to build a Skill, or go to Plugins, then Skills, then Add, and choose Create with chat. This opens Work with the built-in skill-creator, ready to guide you.

<break time="500ms"/>Second, use the editor. Choose Create with editor, enter the Skill's name, description, and instructions, then select Create.

<break time="500ms"/>Third, upload a Skill you already have from your computer.

<break time="500ms"/>Menu labels and options can vary by product and workspace.

<break time="500ms"/>If you're using the ChatGPT desktop app on a Mac, there's one more option, called Record and Replay.

<break time="500ms"/>When you finish recording, ChatGPT uses that demonstration to draft a reusable Skill that you can review and refine.
