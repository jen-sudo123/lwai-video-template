<break time="500ms"/>In this lesson, let's look at how to save your 3Cs Personalization Profile into Microsoft 365 Copilot, so it has a better starting point whenever you begin a new conversation.

<break time="500ms"/>On web and desktop, here's where to find it. Open Microsoft 365 Copilot Chat and sign in with your Microsoft 365 account. In the left corner, select Settings. Select Personalization from the menu on the left. Find Custom instructions and select Edit instructions.

<break time="500ms"/>This opens the space where you can tell Copilot what it should know about you and how you want it to respond.

<break time="500ms"/>A quick note on mobile. Microsoft 365 Copilot is available on both iOS and Android, but Microsoft currently doesn't offer a way to edit your Custom Instructions from the mobile app. For now, set them up through Copilot Chat on web or desktop — you can still use Copilot normally on mobile once they're saved.

<break time="500ms"/>Now let's look at the demo. I've opened Custom instructions.

<break time="300ms"/>Copilot gives me one main instruction field, so I'm going to build my profile using the 3Cs: Context, Communication, and Collaboration.

<break time="400ms"/>First, Context. I'll tell Copilot what it should consistently know about me: "I'm a senior leader responsible for strategy and operations. I regularly use Copilot to prepare for meetings, make decisions, and communicate with my leadership team."

<break time="400ms"/>Next, Communication. This is how I want Copilot to respond: "Be concise and direct. Lead with the key takeaway, use plain business language, and use bullet points when they make information easier to scan."

<break time="400ms"/>And finally, Collaboration. This is how I want Copilot to work with me: "Challenge my assumptions when appropriate. Ask questions when important information is missing, and flag uncertainty rather than guessing."

<break time="400ms"/>Once I'm happy with my 3Cs, I'll select Save instructions.

<break time="500ms"/>And that's it. Copilot now has a starting profile for how I want it to work with me, without me having to repeat these instructions in every conversation.

<break time="500ms"/>Now let's put it into practice. I'll open a new conversation and give Copilot a task to test whether my Custom Instructions actually work.

<break time="400ms"/>The goal here: less time briefing Copilot, more time getting useful work done.

<break time="500ms"/>Before we wrap up, a few practical notes.

<break time="400ms"/>Keep your instructions persistent, not task-specific. Your role, audience, communication preferences, and working style belong here. Details that only matter for one task should stay in the prompt.

<break time="400ms"/>Keep them concise and specific. Microsoft doesn't currently publish a character limit for personal Custom Instructions, so focus on useful standing preferences rather than trying to fill the space.

<break time="400ms"/>Custom Instructions can be turned off. Go back to Personalization and use the toggle on the Custom Instructions tile if you don't want Copilot to apply them.

<break time="400ms"/>And treat your profile as something to refine. When you notice yourself repeatedly correcting Copilot in the same way, ask whether that preference belongs in your Custom Instructions.
