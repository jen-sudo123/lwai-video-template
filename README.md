# LWAI Video Template (Remotion)

Branded video template for Lead with AI. Recreates the VEED template as a Remotion project so videos can be generated by editing a `scenes` array instead of rebuilding a timeline every time.

## Scene layouts

| Layout | Use for |
|---|---|
| `title-card-green` | Bold opening — green bg, yellow circle, white serif title |
| `title-slide-transition` | Animated title transition between sections |
| `blank` | Breathing room, transitions |
| `big-statement` | Full-screen punchy one-liner |
| `text-image-split` | Concept + supporting visual (50/50) |
| `large-label-body-split` | Large eyebrow label + body text split |
| `centered-image-caption` | Tool screenshots, demos |
| `centered-quote` | Hero statements, statistics |
| `stat-hero` | Single large statistic with supporting text |
| `comparison` | "X vs Y" two-column |
| `split-contrast` | Two contrasting concepts side by side |
| `label-title-body` | Eyebrow label + title + body (Practical Notes style) |
| `centered-chart` | Data slides |
| `checklist-slide` | Bulleted or checked list items, animated in sequence |
| `chat-thread` | Human/AI conversation thread |
| `prompt-example` | Prompt box + response example |
| `prompt-box-split` | Prompt on one side, output on the other |
| `process-steps` | Numbered step-by-step flow |
| `methods-slide` | Method/approach cards |
| `three-mode-columns` | Three-column feature comparison |
| `takeaway-stack` | Stacked key takeaway cards |
| `reasoning-chain` | Chain-of-thought reasoning steps |
| `thinking-trace-ui` | Simulated AI thinking trace UI |
| `cot-comparison` | Chain-of-thought before/after comparison |
| `problem-black-box` | Problem → black box → solution diagram |
| `define-range-diagram` | Custom Define the Range diagram |
| `model-picker-locations` | Model picker UI callout |
| `placeholder-image` | Dev placeholder for unfinished scenes |

All layouts auto-apply LWAI brand: white background, IBM Plex Serif headings, Public Sans body, lime accent, logo bottom-left, 80px safe margin.

## Setup (one time)

You need Node.js 18+ installed.

```bash
cd lwai-video-template
npm install
```

## Run the studio

```bash
npm start
```

This opens Remotion Studio in the browser. You'll see all registered compositions. Scrub the timeline, edit any data file, and the preview updates live.

## Render a final MP4

```bash
npx remotion render LwaiVideo out/video.mp4
```

Replace `LwaiVideo` with the composition ID you want to render (e.g. `ChainOfThought`, `FewShotPrompting`).

## How to create a new video

1. **Drop your assets** in `public/`:
   - Voiceover: `public/audio/my-voiceover.mp3`
   - Images: `public/images/screenshot-1.png`, etc.

2. **Create a data file** e.g. `src/data/my-video.ts`:

   ```ts
   export const myVideo: VideoData = {
     audioSrc: 'audio/my-voiceover.mp3',
     scenes: [
       { layout: 'title-card-green', title: 'My Video', durationInFrames: 120 },
       { layout: 'centered-quote', text: '...', durationInFrames: 240 },
     ],
   };
   ```

3. **Register it in `src/Root.tsx`** as a new `<Composition>`:

   ```tsx
   <Composition
     id="MyVideo"
     component={Video}
     durationInFrames={calculateTotalFrames(myVideo.scenes)}
     fps={layout.fps}
     width={layout.width}
     height={layout.height}
     defaultProps={myVideo}
   />
   ```

4. **Render it**:
   ```bash
   npx remotion render MyVideo out/my-video.mp4
   ```

## Timing scenes to a voiceover

Durations are in frames at 30 fps:

| Time | Frames |
|---|---|
| 1s | 30 |
| 3s | 90 |
| 5s | 150 |

For tight sync, run audio through Whisper to get word-level timestamps, then set each scene's `durationInFrames` to match the section it covers.

## Animations

- **Kinetic** (`animation: 'kinetic'`) — word-by-word reveal with slight lift. Best for short punchy text (≤ 60 chars).
- **Fade** (`animation: 'fade'`) — whole block fades in. Best for longer paragraphs.
- **Auto** (default) — picks based on text length.

```ts
{ layout: 'centered-quote', text: '...', animation: 'fade', durationInFrames: 240 }
```

## Adding a new layout

1. Create `src/scenes/MyNewLayout.tsx` (copy an existing scene as a starting point)
2. Add the variant to `Scene` in `src/scenes/types.ts`
3. Add the case to `SceneRenderer.tsx`
