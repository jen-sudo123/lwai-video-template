# LWAI Video Template (Remotion)

Branded video template for Lead with AI. Recreates the VEED template as a Remotion project so videos can be generated by editing a `scenes` array instead of rebuilding a timeline every time.

## What's inside

Eight scene layouts that match the VEED template:

| Layout | Use for |
|---|---|
| `title-card-green` | Bold opening — green bg, yellow circle, white serif title |
| `blank` | Breathing room, transitions |
| `text-image-split` | Concept + supporting visual (50/50) |
| `centered-image-caption` | Tool screenshots, demos |
| `centered-quote` | Hero statements, statistics |
| `comparison` | "X vs Y" two-column |
| `label-title-body` | Eyebrow label + title + body (Practical Notes style) |
| `centered-chart` | Data slides |

All layouts auto-apply LWAI brand: white background, IBM Plex Serif headings, Public Sans body, lime accent, logo bottom-left, 80px safe margin.

## Setup (one time)

You need Node.js 18+ installed.

```bash
cd lwai-video-template
npm install
```

## Run the studio

```bash
npm start
```

This opens Remotion Studio in the browser. You'll see the sample video. Scrub the timeline, edit `src/data/sample-scenes.ts`, and the preview updates live.

## Render a final MP4

```bash
npx remotion render LwaiVideo out/video.mp4
```

## How to create a new video

1. **Drop your assets** in `public/`:
   - Voiceover: `public/audio/my-voiceover.mp3`
   - Images: `public/images/screenshot-1.png`, etc.
   - Charts: export as PNG and drop in `public/images/`

2. **Edit `src/data/sample-scenes.ts`** (or copy it to a new file like `my-video.ts`):

   ```ts
   export const myVideo: VideoData = {
     audioSrc: 'audio/my-voiceover.mp3',
     scenes: [
       { layout: 'title-card-green', title: 'My Video', durationInFrames: 120 },
       { layout: 'centered-quote', text: '...', durationInFrames: 240 },
       // ... more scenes
     ],
   };
   ```

3. **Register it in `src/Root.tsx`** as a new `<Composition>`:

   ```tsx
   <Composition
     id="MyVideo"
     component={Video}
     durationInFrames={calculateTotalFrames(myVideo.scenes)}
     fps={layout.fps}
     width={layout.width}
     height={layout.height}
     defaultProps={myVideo}
   />
   ```

4. **Render it**:
   ```bash
   npx remotion render MyVideo out/my-video.mp4
   ```

## Timing the scenes to a voiceover

The scene-by-scene durations are in frames at 30 fps. Quick conversions:

- 1s = 30 frames
- 3s = 90 frames
- 5s = 150 frames

For tight voiceover sync, run the audio through Whisper to get word-level timestamps, then set each scene's `durationInFrames` to match the section it covers.

This is exactly what the production-brief workflow is designed to feed in. A Claude skill can take (script + Whisper transcript) and output a complete `scenes` array with timings already filled in.

## Animations

Two modes:

- **Kinetic** (`animation: 'kinetic'`) — each word reveals one at a time with a slight lift. Best for short, punchy text (≤ 60 chars).
- **Fade** (`animation: 'fade'`) — whole block fades in together. Best for longer paragraphs.
- **Auto** (default) — picks based on text length.

Override per scene if needed:
```ts
{ layout: 'centered-quote', text: '...', animation: 'fade', durationInFrames: 240 }
```

## Brand tokens

All colors, fonts, and dimensions live in `src/tokens.ts`. Edit there to change anything globally.

## Adding a new layout

If you need a layout the template doesn't have:

1. Create `src/scenes/MyNewLayout.tsx` (copy an existing scene as a template)
2. Add the variant to `Scene` in `src/scenes/types.ts`
3. Add the case to `SceneRenderer.tsx`

That's it. Once added, it works in any scene array.
